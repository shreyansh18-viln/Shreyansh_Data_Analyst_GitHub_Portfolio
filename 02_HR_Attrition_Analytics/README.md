# HR Attrition Analytics
**Tools:** Excel, Python (Pandas), MySQL, Power BI

## Objective
Explore the provided synthetic practice dataset and answer business questions using Python, SQL, Excel and Power BI.

## Files
- `data/hr_employee_data.csv` — generated fictional dataset
- `excel/analysis_workbook.xlsx` — raw data and summary sheets
- `python/analysis.py` — Python analysis starter
- `sql/analysis.sql` — table definition and business queries
- `powerbi/measures.dax` — DAX measure examples
- `powerbi/dashboard_build_guide.md` — steps to build your own Power BI report

## Run Python
```bash
pip install -r requirements.txt
python python/analysis.py
```
Import the CSV into MySQL Workbench and run `sql/analysis.sql`. Open the Excel workbook and inspect the summary sheets. Follow the Power BI guide and save your own `.pbix` file in the `powerbi` folder.

## Important
All records are generated synthetic learning data, not real business, employee or banking records. This is a starter project: run and verify the analysis, build the Power BI report, add screenshots and write your own findings before presenting it as completed.
