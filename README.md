# Shreyansh Rathore — Data Analyst Portfolio Starter Pack
Three beginner-friendly, end-to-end project starters:
1. E-commerce Sales Analytics
2. HR Attrition Analytics
3. Banking Transaction Analytics

Each project contains a synthetic CSV dataset, Excel workbook, Python analysis script, MySQL schema/queries, Power BI DAX measures, dashboard build guide and README.

## Recommended workflow
1. Pick one project folder and read its README.
2. Run the Python analysis.
3. Import its CSV into MySQL Workbench and run the SQL.
4. Review the Excel workbook.
5. Build the Power BI report using the guide and save the `.pbix` file.
6. Add dashboard screenshots and your own verified findings to README.
7. Upload the repository to GitHub.

**Integrity note:** These are starter projects, not completed portfolio claims. All datasets are synthetic. Do not say you completed a project until you have run, checked and understood every part.
